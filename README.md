# 💰 간단 가계부

별도 설치나 빌드 과정 없이 브라우저에서 바로 실행되는 정적 가계부 웹앱입니다.

## 기능

- 수입/지출 내역 등록 (날짜, 카테고리, 금액, 메모)
- 월별 보기 (이전/다음 달 이동)
- 월별 수입/지출/잔액 요약
- 전체/수입/지출 필터
- 내역 삭제
- 데이터는 브라우저 `localStorage`에 저장 (별도 서버·DB 불필요)

## 실행 방법

`index.html`을 더블클릭해서 열어도 되지만, 브라우저 보안 정책상 로컬 서버로 여는 것을 권장합니다.

```bash
npx serve .
```

또는 Python이 있다면:

```bash
python3 -m http.server 8080
```

이후 브라우저에서 안내된 주소(예: `http://localhost:3000`, `http://localhost:8080`)로 접속하세요.

## 파일 구성

- [index.html](index.html) — 화면 구조
- [style.css](style.css) — 스타일 (라이트/다크 모드 자동 대응)
- [script.js](script.js) — 데이터 저장·렌더링 로직 (바닐라 JS)

## 데이터 보관 안내

모든 내역은 접속한 브라우저의 `localStorage`에만 저장됩니다. 브라우저 저장소를 지우거나 다른 브라우저/기기로 접속하면 내역이 보이지 않으니 참고하세요.
