# 💰 간단 가계부

별도 설치나 빌드 과정 없이 브라우저에서 바로 실행되는 가계부 웹앱입니다. 데이터는 Supabase(Postgres) DB에 저장됩니다.

## 기능

- 수입/지출 내역 등록 (날짜, 카테고리, 금액, 메모)
- 월별 보기 (이전/다음 달 이동)
- 월별 수입/지출/잔액 요약
- 월별 지출 예산 설정 및 사용률(%) 진행률(Progress Bar) 표시
  - 사용률 80% 이상: 주의 표시, 100% 초과: 예산 초과 경고 표시
- 전체/수입/지출 필터
- 내역 삭제
- 데이터는 Supabase의 `transactions`, `budgets` 테이블에 저장 (브라우저 간 공유됨)

## 실행 방법

`index.html`을 더블클릭해서 열어도 되지만, 브라우저 보안 정책상 로컬 서버로 여는 것을 권장합니다.

```bash
npx serve .
```

또는 Python이 있다면:

```bash
python3 -m http.server 8080
```

이후 브라우저에서 안내된 주소(예: `http://localhost:3000`, `http://localhost:8080`)로 접속하세요.

## 파일 구성

- [index.html](index.html) — 화면 구조
- [style.css](style.css) — 스타일 (라이트/다크 모드 자동 대응)
- [script.js](script.js) — 데이터 저장·렌더링 로직 (바닐라 JS)

## 데이터 보관 안내

모든 내역은 Supabase 프로젝트의 `transactions`, `budgets` 테이블에 저장되어 어떤 브라우저·기기로 접속해도 동일한 데이터를 볼 수 있습니다. 현재는 별도 로그인 없이 anon 키로 테이블 전체에 접근하는 구조이므로, 개인 용도로만 사용하는 것을 권장합니다.
